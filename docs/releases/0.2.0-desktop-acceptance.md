## Restart, edit, and deletion

**Edit:** Replaced Weekend garden's content in the Obsidian editor and saved:

```markdown
# Weekend garden

The solar irrigation controller uses an emergency backup battery. Recharge that battery every Friday and inspect its cable connections.
```

Without manual reindexing, the query **When should I recharge the solar
irrigation controller's backup battery?** returned Weekend garden first at
85%, showing the updated snippet. The index still reported six chunks.

**Failed rebuild and restart:** Selected the intentionally missing model
`odex-missing-model-audit` and clicked **Rebuild**. The request returned HTTP
404. The previous six-note index remained searchable with the active provider,
including the edited garden result at 85%. Quit Obsidian with Command-Q,
reopened it, and selected the synthetic vault. It reported six ready chunks
and returned the same battery-query results even though Settings still held
the failed candidate model. This verifies recovery of the saved active
provider independently of the selected candidate settings.

**Successful retry:** Restored `nomic-embed-text` and clicked **Rebuild**.
Indexing completed with six ready chunks.

**Deletion:** Deleted synthetic Night sky through Obsidian's file menu,
confirming the dialog that moved it to system trash. The index reported five
chunks. The query **How can I observe Jupiter's Galilean moons?** returned only
the other five notes, with Night sky absent.

**Restore:** Restored the original Weekend garden and Night sky fixture files
after the checks. The UI returned to six ready chunks and the original
vegetables query again produced the original six results and scores.

The combined source passed 140 tests, type checking, release metadata checks,
and the production build. Its bundle was 222 KB against the 3072 KB limit.
Known nonblocking UI issues: scores touch snippet text, and the failed-rebuild
message could state more clearly that the previous index remains available.

## Release boundary

This record accepts the source and installed bundle identified above. It
neither records an official GitHub release nor accepts an untested replacement
bundle. Before tagging the final reviewed merge, rebuild it and compare the
`main.js` SHA-256 with this record. If the bundle changes, repeat the desktop
walkthrough and update its identity and observations. Required CI, independent
review, and the official release assets remain separate gates in the
[release checklist](0.2.0.md).

Mobile, other providers, other models, and larger or personal vaults were not
part of this run.
